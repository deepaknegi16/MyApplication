Hotel Service — Request Flow

Spring Boot layered architecture: Controller → Service → Repository → Database  ·  repo: deepaknegi16/MyApplication

0The big picture

Every hotel request passes through the same layers. Each layer has one job and only talks to the layer directly below it — the controller never touches the repository, and the service knows nothing about HTTP.

Client
curl / Swagger UI — sends JSON + Authorization: Bearer <JWT>
▼ HTTP request
Security filter chain — SecurityConfig
Validates the JWT, extracts roles. GET needs USER/ADMIN; POST, PUT, DELETE need ADMIN. Fails → 401/403 before any controller code runs.
▼
Controller — HotelController (@RestController)
Maps URL + HTTP method to a Java method, validates input (@Valid, @Positive), builds the HTTP response. No business logic.
▼ Java method call
Service — HotelServiceImpl (@Service, @Transactional)
Business rules: soft-delete filtering, city must exist, distance sorting, caching, events. Throws ResourceNotFoundException → 404.
▼
Repository — HotelRepository (Spring Data JPA)
Interface only — Spring generates the SQL from method names or @Query. CRUD via JpaRepository.
▼ JDBC / SQL
Database — H2 in-memory (hotel, city tables)
Schema generated from the @Entity classes; seeded by data.sql on startup.

1Example walk-through: POST /hotel

LayerWhat happens
ClientSends JSON body {"name":"The Oberoi", "latitude":28.60, "longitude":77.24, "rating":5, "cityId":1, "time":"2026-08-18T09:15:00"} with an admin JWT.
SecurityPOST /hotel requires ROLE_ADMIN — a USER token stops here with 403.
ControllerJackson turns the JSON into a CreateHotelRequest record; @Valid runs the constraints (rating 1–5, lat/lon in range, time not null). Invalid → 400 problem-detail.
ServiceLoads the City by cityId — unknown city → ResourceNotFoundException → 404. Builds the Hotel entity, sets the client-supplied time.
Repositorysave(hotel) → INSERT INTO hotel …; the DB generates the id; JPA auditing stamps createdAt/updatedAt.
ControllerReturns 201 Created with a Location: /hotel/{id} header and the saved hotel as JSON.
Errors take a shortcut: any exception thrown below the controller is caught by GlobalExceptionHandler (@RestControllerAdvice) and converted into an RFC 7807 application/problem+json response — the controller never handles errors itself.

2Controller layer

Thin HTTP adapter: annotations map routes, constraints validate input, and every method is one delegation to the service. (Swagger @Operation/@ApiResponses annotations omitted here for brevity.)

src/main/java/com/hackerrank/hotel/controller/HotelController.java 
@RestController
@Validated
public class HotelController {

    private final HotelService hotelService;          // injected via constructor

    @Autowired
    public HotelController(HotelService hotelService) {
        this.hotelService = hotelService;
    }

    @GetMapping("/hotel/{id}")                        // Q1: fetch one hotel
    public ResponseEntity<Hotel> getHotelById(@PathVariable @Positive Long id) {
        return ResponseEntity.ok(hotelService.getHotelById(id));
    }

    @PostMapping("/hotel")                            // create (ADMIN) — 201 + Location
    public ResponseEntity<Hotel> createHotel(@Valid @RequestBody CreateHotelRequest request) {
        Hotel created = hotelService.createHotel(request);
        return ResponseEntity.created(URI.create("/hotel/" + created.getId())).body(created);
    }

    @PutMapping("/hotel/{id}")                        // update (ADMIN)
    public ResponseEntity<Hotel> updateHotel(@PathVariable @Positive Long id,
                                             @Valid @RequestBody UpdateHotelRequest request) {
        return ResponseEntity.ok(hotelService.updateHotel(id, request));
    }

    @DeleteMapping("/hotel/{id}")                     // Q2: soft-delete (ADMIN) — 204
    public ResponseEntity<Void> deleteHotelById(@PathVariable @Positive Long id) {
        hotelService.deleteHotelById(id);
        return ResponseEntity.noContent().build();
    }

    @GetMapping("/search/{cityId}")                   // Q3: nearest-first city search
    public ResponseEntity<List<HotelSearchResult>> searchHotels(
            @PathVariable @Positive Long cityId,
            @RequestParam(name = "limit", required = false) @Positive Integer limit) {
        return ResponseEntity.ok(hotelService.searchHotelsClosestToCityCenter(cityId, limit));
    }

    @GetMapping("/hotel/search")                      // name search across all cities
    public ResponseEntity<List<HotelNameSearchResult>> searchHotelsByName(
            @RequestParam(name = "name", required = false) String name,
            @RequestParam(name = "limit", required = false) @Positive Integer limit) {
        return ResponseEntity.ok(hotelService.searchHotelsByName(name, limit));
    }
}

The request bodies are plain Java DTO classes: Jackson builds them through the no-args constructor and setters, and the bean-validation constraints on the fields run automatically because of @Valid:

    private Double latitude;

    @NotNull @DecimalMin("-180.0") @DecimalMax("180.0")

    @NotNull

    public void setName(String name) { this.name = name; }

3Service layer

All business rules live here, behind the HotelService interface. The controller depends only on this interface — the implementation can be swapped (or mocked in tests) without touching the controller:

src/main/java/com/hackerrank/hotel/service/HotelService.java 
public interface HotelService {

    /** Q1: fetch a hotel by id (404 if missing or soft-deleted). */
    Hotel getHotelById(Long id);

    /** Create a new hotel in an existing city (404 if the city is unknown). */
    Hotel createHotel(CreateHotelRequest request);

    /** Update a hotel's editable fields (404 if missing or soft-deleted). */
    Hotel updateHotel(Long id, UpdateHotelRequest request);

    /** Q2: soft-delete — mark the hotel as deleted, keep the row. */
    void deleteHotelById(Long id);

    /** Q3: active hotels of a city, sorted by haversine distance to the
        city center. A null limit returns all of them. */
    List<HotelSearchResult> searchHotelsClosestToCityCenter(Long cityId, Integer limit);

    /** Active hotels across all cities whose name contains the given text
        (case-insensitive), sorted by name. */
    List<HotelNameSearchResult> searchHotelsByName(String name, Integer limit);
}

The implementation carries the Spring machinery: @Transactional wraps each method in a DB transaction; @Cacheable/@CacheEvict keep single-hotel reads cached and evict on writes.

src/main/java/com/hackerrank/hotel/service/HotelServiceImpl.java 
@Service
public class HotelServiceImpl implements HotelService {

    private final HotelRepository hotelRepository;
    private final CityRepository cityRepository;
    private final DistanceCalculator distanceCalculator;      // haversine impl injected
    private final ApplicationEventPublisher eventPublisher;

    @Override
    @Transactional(readOnly = true)
    @Cacheable(cacheNames = "hotels", key = "#id")
    public Hotel getHotelById(Long id) {
        Hotel hotel = hotelRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Hotel not found with id: " + id));
        if (hotel.isDeleted()) {                              // soft-deleted rows look missing
            throw new ResourceNotFoundException("Hotel not found with id: " + id);
        }
        return hotel;
    }

    @Override
    @Transactional
    public Hotel createHotel(CreateHotelRequest request) {
        City city = cityRepository.findById(request.cityId()) // fail fast: clean 404, not an FK error
                .orElseThrow(() -> new ResourceNotFoundException(
                        "City not found with id: " + request.cityId()));
        Hotel hotel = new Hotel(request.name(), request.latitude(),
                                request.longitude(), request.rating(), city);
        hotel.setTime(request.time());                        // client-supplied timestamp
        return hotelRepository.save(hotel);                   // INSERT, id generated by DB
    }

    @Override
    @Transactional
    @CacheEvict(cacheNames = "hotels", key = "#id")
    public Hotel updateHotel(Long id, UpdateHotelRequest request) {
        Hotel hotel = hotelRepository.findById(id)
                .filter(h -> !h.isDeleted())
                .orElseThrow(() -> new ResourceNotFoundException("Hotel not found with id: " + id));
        hotel.setName(request.name());
        hotel.setLatitude(request.latitude());
        hotel.setLongitude(request.longitude());
        hotel.setRating(request.rating());
        hotel.setTime(request.time());
        // no explicit save needed: dirty checking flushes the UPDATE at commit
        return hotel;
    }

    @Override
    @Transactional
    @CacheEvict(cacheNames = "hotels", key = "#id")
    public void deleteHotelById(Long id) {
        Hotel hotel = hotelRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Hotel not found with id: " + id));
        hotel.setDeleted(true);                               // soft delete — row stays
        hotelRepository.save(hotel);
        eventPublisher.publishEvent(new HotelDeletedEvent(
                hotel.getId(), hotel.getName(), currentUsername()));
    }

    @Override
    @Transactional(readOnly = true)
    public List<HotelSearchResult> searchHotelsClosestToCityCenter(Long cityId, Integer limit) {
        City city = cityRepository.findById(cityId)
                .orElseThrow(() -> new ResourceNotFoundException("City not found with id: " + cityId));
        var results = hotelRepository.findByCityIdAndDeletedFalse(cityId).stream()
                .map(hotel -> toSearchResult(hotel, city))    // computes haversine distance
                .sorted(Comparator.comparingDouble(HotelSearchResult::distanceFromCityCenterKm));
        if (limit != null) results = results.limit(limit);
        return results.toList();
    }
}

4Repository layer

Just an interface — Spring Data JPA generates the implementation and the SQL at startup. Method names are parsed into queries; @Query is used where a name would get unreadable.

src/main/java/com/hackerrank/hotel/repository/HotelRepository.java 
@Repository
public interface HotelRepository extends JpaRepository<Hotel, Long> {

    // derived query: parsed into "where city_id = ? and deleted = false"
    List<Hotel> findByCityIdAndDeletedFalse(Long cityId);

    // case-insensitive substring match on the name, across all cities
    List<Hotel> findByDeletedFalseAndNameContainingIgnoreCaseOrderByNameAsc(String name);

    // hand-written JPQL for when a method name would get unreadable
    @Query("select count(h) from Hotel h where h.deleted = false")
    long countActive();

    @Query("select count(h) from Hotel h where h.deleted = false and h.city.id = :cityId")
    long countActiveInCity(@Param("cityId") Long cityId);
}

5Entity — what actually lands in the database

Hibernate maps this class to the hotel table (ddl-auto=create builds the schema from it on startup). Note the three different timestamps.

src/main/java/com/hackerrank/hotel/model/Hotel.java (fields) 
@Entity
@Table(name = "hotel")
@EntityListeners(AuditingEntityListener.class)
public class Hotel {

    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 120)
    private String name;

    private double latitude;
    private double longitude;
    private int rating;

    private boolean deleted;              // soft-delete flag: row is never removed

    @Column(name = "time")                // client-supplied via POST/PUT body
    private LocalDateTime time;

    @ManyToOne @JoinColumn(name = "city_id")
    private City city;                    // FK → city table

    @CreatedDate  @Column(name = "created_at", updatable = false)
    private Instant createdAt;            // stamped automatically by JPA auditing

    @LastModifiedDate @Column(name = "updated_at")
    private Instant updatedAt;            // re-stamped on every update
}

6Error path — one handler for every layer

src/main/java/com/hackerrank/hotel/exception/GlobalExceptionHandler.java (excerpt) 
@RestControllerAdvice
public class GlobalExceptionHandler extends ResponseEntityExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)        // service throws → client gets 404
    public ProblemDetail handleNotFound(ResourceNotFoundException ex) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
        problem.setTitle("Resource not found");
        return problem;
    }

    @ExceptionHandler(Exception.class)                        // anything unexpected → generic 500
    public ProblemDetail handleUnexpected(Exception ex) {
        log.error("Unhandled exception", ex);                 // log details, never leak them
        return ProblemDetail.forStatusAndDetail(HttpStatus.INTERNAL_SERVER_ERROR,
                "An unexpected error occurred. Please try again later.");
    }
}
